■ 캐릭터 파일 규격 (이 폴더에 .json 을 넣으면 다음 실행 때 자동 등록됩니다)

파일 위치 = UI의 폴더 구조:
  캐릭터/이름.json                → 폴더 없음
  캐릭터/폴더명/이름.json          → 폴더
  캐릭터/폴더명/하위폴더/이름.json  → 하위폴더

파일 내용 (JSON):
{
  "이름": "레이나",
  "외형": "girl, black hair, long hair, black eyes, large breasts",
  "착의": "girl, black hair, ..., school uniform",
  "네거티브": "choker, sword",
  "출처": "https://wiki.dorang.uk/..."
}

- "외형"만 필수. 나머지는 선택.
- "외형" 대신 "그룹"으로 나눠 적어도 됩니다 (아래 순서로 자동 조합):
{
  "이름": "키사키",
  "그룹": {
    "기본": "kisaki",
    "상황": "",
    "행동": "",
    "외모": "black hair, twintails, red eyes",
    "의상": "china dress",
    "장신구": "hair ornament",
    "마무리": ""
  }
}

- UI에서 캐릭터를 수정하면 이 파일에도 저장되고, UI에서 삭제하면 파일도 삭제됩니다.
- 위키 등에서 수집한 프롬프트를 이 규격으로 만들어 폴더째 복사하면 대량 등록됩니다.
