# NAI 배치 생성기

NovelAI 로 **많은 장을 계획적으로 뽑기 위한 보조 프로그램**이다.
파이썬 파일 하나(`start.py`)가 서버와 화면을 함께 들고 있고, 브라우저에서 조작한다.
NovelAI 의 공식 제품이 아니며 NovelAI 와 아무 관계가 없다.

## 시작

**Windows x64 전용**이다 (임베디드 파이썬 자동 설치가 Windows용이다).
`실행.bat` 더블클릭 → 파이썬이 없으면 알아서 내려받아 준비하고 브라우저가 열린다.
자동 준비에는 인터넷 연결과 Windows 기본 도구(curl · tar · PowerShell)가 필요하다 —
Windows 10 1803 이후면 다 들어 있다. 실패하면 [python.org](https://www.python.org/downloads/)에서
파이썬을 설치한 뒤 `python start.py` 로 직접 실행하면 된다.
`기타 → API` 에 NAI 토큰을 넣으면 끝이다.
(토큰 발급: novelai.net → 설정 → Account → Get Persistent API Token)

> ⚠ 토큰은 계정 열쇠다. 공유하지 말 것. 무제한 생성은 Opus 구독이 필요하다.

파이썬을 직접 쓰려면 `requests` 와 `pillow` 만 있으면 된다.
검증한 직접·전이 의존성의 정확한 버전은 `requirements.txt`에 고정했다.
`실행.bat`도 같은 파일로 설치한다.
(`실행.bat`은 Python 3.12.8 임베디드판을 SHA-256 확인 후 내려받는다.)
```
pip install -r requirements.txt
python start.py
```
계정이 둘이면 `실행_둘째계정.bat` (또는 `실행.bat --profile 이름`).
프로필마다 토큰·설정·생성물이 갈리고 포트도 자동으로 갈린다(8787·8788…).
⚠ 같은 계정으로 두 대를 돌리지는 말 것 — 요청이 겹쳐 제한에 걸릴 위험이 커진다.

## 화면 (탭 5개 · Alt+1~5)

| 탭 | 담는 것 |
|---|---|
| **🖼 생성** | 첫 화면 드롭존(그림에서 설정 읽기) · 실시간 미리보기 · **고쳐 그리기**(img2img·인페인트) · **디렉터 툴**(배경제거·라인아트·스케치·색칠·표정·정리·업스케일) |
| **📚 자료** | **생성물 탐색기**(선별·비교함·그림체 복구) · 단부루 검색 · 그림체·캐릭터 라이브러리 · 남들의 조합(레시피) |
| **🧰 빌더** | 베이스 빌더(11단계 42슬롯) · 캐릭터 빌더(17단계 76슬롯) · 태그 사전 검색 |
| **🎬 세팅** | 세팅(씬 묶음 배치) · 씬 모드(가벼운 낱개) · **세팅 빌더** |
| **⚙ 기타** | API · 화면·디자인 · 계정 여러 개 · 알림·단축키 · 모자이크 · 밴 예방 · 메타데이터 제거 · 파일 구조 |

왼쪽 프롬프트 패널은 늘 보인다 — 프롬프트·네거티브 + `캐릭터 · 레퍼런스 · 파라미터 · 조각` 오버레이.

## 주요 기능

**NAI 기능** — 생성 · img2img · 인페인트(붓 2~300px·지우개·되돌리기·50~200% 배율) ·
바이브 트랜스퍼 · 캐릭터 레퍼런스 · 디렉터 툴 6종 · 업스케일 · **인물 최대 6명 + 좌표 격자** ·
생성 파라미터 노출(모델·해상도·CFG·리스케일·스텝·샘플러·스케줄·UC 프리셋·퀄리티 태그·
Variety+·시드 + 고급 항목, 모델 세대별로 잠금) · T5 토큰 수 · Anlas 견적·잔액·무료 판정

**배치** — **세팅**: 씬이 5장 묶음이고 옵션이 씬 문맥의 함수인 구조(체위 113세트 565장 같은 것).
단계만 골라 뽑기, 세트별 예약 매수, 캐릭터별로 몰아 생성.
**씬 모드**: 이름·프롬프트·해상도만 있는 낱개 + 예약.
**조각**: `<이름>` 무작위 / `<*이름>` 차례대로 / `{a|b|c}` — 위 세 곳 어디서나 먹는다.
셋은 서로를 대체하지 않는다.

**정리** — 탐색기에서 F 선별 · S 즐겨찾기 · C 비교함 · ←→ 넘기기 ·
**그림체 복구**(그림의 메타를 읽어 같은 설정으로 다시 뽑기) · 선별 외 삭제

**태그 검증** — 프롬프트 칸의 `✓태그` 를 누르면 단부루에 실제로 있는 태그인지 확인한다.
게시물 수 · **이름이 바뀐 것(눌러서 새 이름으로 교체)** · 폐지된 것 · 정말 없는 것을 구분해 보여 준다.
없는 태그는 그림에 영향 없이 토큰만 먹는다. (태그 2개 제한이 없는 경로를 쓰므로 프롬프트 전체를 한 번에)

**메타데이터** — PNG 텍스트 청크 · WebP EXIF · **스텔스(알파 채널)** 까지 읽는다.
그림을 창에 끌어다 놓으면 프롬프트·네거티브·설정값이 통째로 들어온다.
반대로 **저장할 때 메타를 아예 안 넣거나**(공유용) 이미 뽑은 그림에서 지울 수도 있다.

**밴 예방** — 장 사이 간격, 짧게/길게 쉬기, 일일 상한. 쉬는 자리는 항상 장과 장 사이다.

## 알려진 문제 · 아직 안 한 것

- **단부루 검색은 비로그인 태그 2개까지**다. `기타 → API` 에 단부루 계정을 넣으면 6개까지
  된다(골드 이상). 겔부루는 API 키가 있어야 검색되고, e621 은 한국에서 지역 차단(451)이다.
- 단부루 본 도메인이 막히면 **미러(hijiribe·sonohara)로 자동 우회**한다. 태그 2개 제한은
  미러에서도 같다 — 미러는 차단만 넘는다.
- **태그 자동완성은 처음 켤 때 한 번 15초쯤** 걸린다(사전 22만개 로드 + 색인).
  색인을 `수집/태그색인.pickle` 에 저장하므로 **그다음 실행부터는 1초 안**이고, 검색 자체는 10~80ms 다.
- 세팅에는 씬 모드의 **임의 인물 칸**과 **세트 순서 드래그**가 없다. 세팅은 방식(단독/남녀/백합)이
  조립 규칙을 정하는 구조라, 넣으려면 방식 설계를 손대야 한다.
- **씬 번호는 세팅끼리 공유하는 전역 이름공간**이다. 겹치면 경고가 뜨고
  세팅 빌더의 `번호 다시 매기기` 로 푼다.
- **캐릭터 레퍼런스의 `information_extracted` 는 NAI 가 1.0 으로 강제**한다
  (세기·충실도는 -0.5~2.0 까지 조절된다). 참조 이미지는 자동으로 허용 캔버스에 맞춰 넣는다.
- **퀄리티 태그와 UC 프리셋은 Anime V3·Furry V3·V4 Curated/Full·V4.5
  Curated/Full의 모델별 공식 문구**를 합친다. 모델을 바꾸거나 메타데이터를 복원해도
  현재 모델에 맞는 문구만 제거·재적용한다.
- 다국어 없음(한국어 전용) · 스트리밍 미리보기 없음(완료 후 표시) · 자동 업데이트 없음.
- **565장 장기 배치 완주와 밴 예방의 실효성은 아직 길게 돌려 확인하지 않았다.**
- 다른 PC 에서의 첫 실행(임베디드 파이썬 자동 준비)은 내 PC 에서만 확인했다.
- 바이브의 `information_extracted` 값과 인페인트의 `request_type` 효과는 다른 구현과
  전송값이 달라, 동일 계정·동일 입력의 실비용 A/B 전까지 완전한 패리티를 단정하지 않는다.
- 아직 공개되지 않은 다음 세대 모델(NAI 5)은 지원 대상이 아니다.

## 무엇이 어디에 들어 있나

저장소(`git`)와 배포본(`배포준비.py` 산출 ZIP)에 들어가는 것이 다르다.

| 자료 | 저장소 | 배포본 ZIP | 비고 |
|---|---|---|---|
| `start.py`·실행.bat·문서·`requirements.txt`·`규격.json`·`옵션.json`·`후보사전.json` | ✅ | ✅ | 프로그램 본체 |
| `t5_tokenizer.json` (2.3MB) | ❌ | **✅** | 토큰 수 계산용 vocab |
| `태그/*.csv` (6MB) | ❌ | **✅** | 자동완성·빌더 사전 |
| 그림체·작가통계·레시피·이미지캐시 (수집물) | ❌ | ❌ | `자료팩.zip` 으로만 따로 전달 |
| `설정.txt` (값 비운 템플릿) | ❌ | ✅ | 배포본에는 **값이 지워진 채**로 들어간다 |
| `tests/test_regressions.py` | ✅ | ✅ | 무과금 회귀 시험 (NAI 호출 없음) |
| 설정·토큰·생성물·프로필·세팅·조각 | ❌ | ❌ | 개인 데이터 |

- **저장소를 clone 한 경우** `t5_tokenizer.json` 과 `태그/*.csv` 가 없다. 그러면 **토큰 수 표시와
  태그 자동완성만 조용히 비어 있고 생성은 정상으로 된다.** 두 파일은 배포본 ZIP 에 들어 있으므로
  ZIP 을 받았다면 따로 구할 필요가 없다.
- **그림체 라이브러리**는 어느 쪽에도 없다. `자료팩.zip` 을 받았다면 압축을 풀어 나온 `수집/`
  폴더를 앱 폴더에 덮어넣으면 채워진다. 없어도 그림을 끌어다 놓아 그림체를 뽑거나 직접 등록해
  쓰는 데는 지장이 없다.

## 아직 없는 것 (후속 로드맵)

비교 프로젝트에 있고 여기에는 아직 없는 기능이다. 필요하면 그쪽을 쓰면 된다.

- Cloudflare R2 직접 업로드 (자격증명 관리가 필요해 미착수)
- 자연어를 태그 프롬프트로 바꿔 주는 AI 보조 (외부 AI 서비스 연결 필요)
- 생성·후처리를 함께 넣는 다종 작업 큐 · 프로젝트 단위 브라우저
- 이름 붙인 내보내기 프리셋 · 슬롯 기반 일괄 정리 · 씬 인물 무작위 추첨
- 색상 덧그리기·블러 브러시 (인페인트 붓·모자이크는 있다)
