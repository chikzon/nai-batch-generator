# 현재 작업

상태: **완료 — `15f3b7e`**

## 목적

작가 조합 작업공간을 열 때 멈추거나 오래 버벅이는 문제를 실제 보유 자료 규모에서
재현하고, 기존 기능을 줄이지 않은 채 첫 화면·검색·조합 갱신을 가볍게 만든다.

`작가 조합 열기 → 필요한 첫 묶음만 표시 → 검색·필터 → 조합/가중치 편집 → 저장`

## 완료 조건

- 732건 이상 실제 자료에서 열기·검색·필터·가중치 다시 뽑기의 시간을 각각 잰다.
- 접힌 영역·화면 밖 카드·대형 이미지와 통계는 필요할 때만 계산·렌더한다.
- 직접·균형·곡선·행별 무작위·고정 작가·순서·초안 복원 기능을 유지한다.
- 같은 입력과 seed의 작가·가중치 결과가 최적화 전후에 바뀌지 않는다.
- 작업 중 취소·화면 전환·재열기에서 초안과 저장본이 오염되지 않는다.
- 관련 기존 성능·작가 조합·렌더 JavaScript 회귀와 소스 서버 스모크를 통과한다.

## 금지 범위

- 작가 조합 알고리즘 의미 변경
- 자료 자동 삭제·자동 병합
- 범용 조건 DSL·완전한 X/Y 그리드
- 6칸 Organizer
- UI 전면 개편 또는 `legacy_app.py` 대규모 재작성
- 스마트폰 앱화
- GitHub push·Release·태그
- 저장소 밖의 `성향 표`와 `로그 편집기`

## 완료 근거

- 실제 `수집/그림체.json` 732건·2.50MB에서 재현·계측
- 검색용 소문자 색인과 출처·게시판·설정값 통계를 자료 로드 때 한 번만 계산
- 평가 필터에서 같은 행의 별점 계산을 한 요청 안에서 한 번만 수행
- 접힌 작가 편집기는 펼칠 때만 초기화
- 검색·필터·재열기의 이전 요청은 취소하고 최신 요청만 화면에 반영
- 50~200장 표시는 20장씩 프레임 사이에 나눠 렌더
- 카드 동작은 목록 하나에서 위임하고 카드 크기는 CSS 변수 한 번으로 변경
- 일반 작업대 초안만 자동 저장하며 빌더 임시 선택은 저장 초안을 오염시키지 않음
- 직접·균형·곡선·행별 무작위·고정·순서 알고리즘은 변경하지 않음

실측 중앙값:

- 기본 20건 검색: 0.63ms
- 문자열 검색: 1.20ms (변경 전 약 56ms)
- 차단 숨김 평가 필터: 20.63ms (변경 전 약 67ms)
- 200건 정렬: 8.58ms
- 20행 고정 seed 무작위 조합: 0.5ms 미만, 반복 결과 동일
- 실행 중 소스 서버: 페이지 HTTP 200 / 42ms, 검색 HTTP 200 / 8ms

검증:

- 관련 기존 회귀·렌더 JavaScript·중복 DOM id 검사 9/9 통과
- Python 문법 검사 통과
- 소스 서버 기동·페이지·검색 API 스모크 통과
- 브라우저 자동 조작 연결은 실행 환경의 브라우저 연결 오류로 재촬영하지 못함
- 전체 회귀·exe·설치본 빌드는 릴리스 후보 단계까지 보류
