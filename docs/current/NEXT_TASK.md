# 현재 작업

상태: **대기 — 다음 코드 작업**

## 목적

자료팩을 가져올 때 새 항목만 조용히 합치는 데서 끝내지 않고, 이름·ID가 겹치는
그림체·캐릭터·레시피를 현재값과 들어오는 값으로 비교해 고른 항목만 반영한다.

`자료팩 검사 → 충돌 자산 비교 → 현재 유지/들어오는 자산 선택 → 기존 자료팩 Undo`

## 완료 조건

- 기존의 누락 항목 자동 추가와 이미지 내용 해시 중복 제거를 유지한다.
- 충돌한 그림체·캐릭터·레시피는 현재값과 들어오는 값을 함께 보여 준다.
- 사용자가 선택하지 않은 기존 자산은 바꾸지 않는다.
- 선택 적용도 기존 자료팩 manifest 검사·원자 저장·판별 Undo를 사용한다.
- 같은 자료팩 재검사, 취소, 실패 뒤 사용자 자료가 유지된다.
- 대형 자료팩은 충돌 목록을 나눠 그려 화면이 멈추지 않는다.
- 직접 관련된 기존 자료팩 테스트와 소스 서버 왕복을 확인한다.

## 금지 범위

- 충돌 자산 자동 덮어쓰기
- 사용자 자료 자동 변환·삭제
- 전체 백업 선택 복원 재작성
- 프로젝트 계층·템플릿 상속 편집
- 캐릭터 제작 Bench
- 범용 조건 DSL
- `legacy_app.py` 대규모 재작성
- 스마트폰 구현
- GitHub push·Release·태그
- 저장소 밖의 `성향 표`와 `로그 편집기`
