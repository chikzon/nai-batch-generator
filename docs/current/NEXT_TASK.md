# 현재 작업

## 목적

캐릭터의 외형, 착의·예술적 변형, 네거티브가 다음 경로에서 손실되지 않게 수정한다.

```text
캐릭터 자료
→ 라이브러리
→ 생성 슬롯
→ 세팅 캐스트
→ 저장 캐스트
→ 최종 payload
```

## 완료 조건

- 각 단계에서 원문이 손실되거나 임의 결합되지 않는다.
- 기존 캐릭터 파일과 사용자 설정을 자동 변환하지 않는다.
- 저장 후 재열기와 앱 재시작 뒤 값이 유지된다.
- 최종 payload에서 외형·착의·네거티브가 확인된다.

## 금지 범위

- 캐릭터 variant 기능 추가
- Reference·Vibe 출연 구성 추가
- UI 전면 개편
- `start.py` 대규모 모듈화
- 외부 앱 재조사
- 테스트 파일 분리
- 관련 없는 새 테스트 추가
