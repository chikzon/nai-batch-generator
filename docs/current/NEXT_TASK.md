# 현재 작업

## 목적

설정·백업·자료팩 되돌리기의 데이터 손실 위험 예외 처리를 수정한다.

## 구현 범위

- 손상되거나 일시적으로 읽지 못한 설정을 정상값처럼 저장하지 않음
- 백업 복원 중 기존 비밀 설정을 읽지 못하면 복원을 중단
- 자료팩 되돌리기에서 파일 이동 실패 시 실패 항목과 로그를 보존
- 정상 경로의 schema·사용자 파일 위치 유지
- 기존 서비스 호출 순서와 응답 schema 유지
- 충돌하는 prefix는 긴 경로를 먼저 판정

## 완료 조건

- 읽기 실패가 설정·비밀값·되돌리기 기록 소실로 이어지지 않음
- 관련 기존 손상 복구·백업·자료팩 undo 테스트 통과
- 관련 기존 회귀 테스트 통과

## 금지 범위

- 저장 schema·사용자 파일 변경
- 세팅·generation POST 라우트 이동
- 전체 회귀·빌드·Release·push
- 저장소 밖의 `성향 표`와 `로그 편집기`

## 다음 경계

데이터 손실 경계 수정 뒤 NAI 호출 인자 계약과 route late binding을 정리한다.
