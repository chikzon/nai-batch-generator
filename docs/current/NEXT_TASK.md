# 현재 작업

## 목적

생성 설계도 연구실의 데스크톱 통합을 끝낸다. 이미 끝난 외부 앱 조사를 반복하지
않고, 기존 근거를 실제 동작으로 연결한다.

현재 한 작업의 범위는 다음 세 갈래를 한 릴리스 후보로 닫는 것이다.

- 복원 입력: 단건 이미지·자료팩·공개 수집·보유 폴더 메타데이터 감사를 같은
  복원 후보와 증거 흐름으로 연결
- 실험 확장: 캐릭터×세팅과 사용자가 고른 그림체·캐릭터·세팅을 실제 비교 셀로
  실행하고 중단·재개·한 셀 재실행까지 연결
- 실행·보존: 생성 설계도와 실제 payload·Job·결과 계보를 잇고 결과를 평가·지식
  갱신 후보로 되돌림

## 완료 조건

- 기능마다 화면 진입점, 실제 데이터 처리, 저장·재시작 유지, 실패 처리까지 연결
- 긴 프롬프트와 그림체·캐릭터·세팅 원문 및 좌표·Reference·Vibe 무손실
- 대형 자료 상태 조회가 전체 큐를 매번 재생성하지 않음
- 모든 NAI 호출은 직렬 실행되고 Job·결과 계보가 재시작 뒤 복구됨
- 관련 기능 테스트와 실제 앱 기동을 통과하고 최종 exe·설치본을 새로 만듦
- 개인 API 토큰·사용자 설정·대용량 자료가 저장소와 배포 본체에 포함되지 않음

## 금지 범위

- 이미 끝난 비교 앱 전수조사 반복
- 사용자 자료 자동 변환·삭제
- 기능별로 중복 엔진·중복 화면 추가
- 근거 없는 기능 흡수와 대규모 일괄 재작성
- GitHub push·Release·태그 생성
- 저장소 밖의 `성향 표`와 `로그 편집기`
