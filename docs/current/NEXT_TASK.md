# 현재 작업

상태: **대기 — 다음 코드 작업**

## 목적

자료팩·백업·외부 편집본을 가져올 때 현재값·들어오는 값·공통 기준을 한 화면에서
비교하고, 충돌 항목만 사용자가 선택해 복원한다.

`현재 저장값 → 가져올 snapshot → 항목별 차이 → 현재 유지/들어오는 값 적용 → 원자 저장`

## 완료 조건

- 그림체·캐릭터·세팅·프로필의 충돌을 항목별로 구분한다.
- 현재값과 들어오는 값을 원문 손실 없이 함께 보여 준다.
- 사용자가 고르기 전에는 어느 쪽도 덮어쓰지 않는다.
- 전체 snapshot 복원과 선택 복원이 같은 검증·백업·Undo 경계를 사용한다.
- 취소·실패·앱 재시작 뒤 현재 사용자 자료가 유지된다.
- 실제 충돌 자료로 직접 관련 기존 테스트와 브라우저 흐름을 확인한다.

## 금지 범위

- 자동 병합으로 사용자 선택을 추측
- 사용자 자료 자동 변환·삭제
- 프로젝트 계층·템플릿 상속 편집
- 캐릭터 제작 Bench
- 범용 조건 DSL
- `legacy_app.py` 대규모 재작성
- 스마트폰 구현
- GitHub push·Release·태그
- 저장소 밖의 `성향 표`와 `로그 편집기`
