# 현재 작업

상태: **완료** (`9f39a59`)

## 목적

기존 기능과 사용자 자료를 유지하면서 생성 화면을 NAI·NAIS 계열의 익숙한 순서로
정돈하고, 흩어진 기능을 하나의 현재 생성 흐름으로 연결한다.

`현재 작업 불러오기·입력 → 고정값·변경값 결정 → 비용 확인 → 생성 → 결과 재사용`

## 이번 단계

- 캐릭터 위치 방식 `AI 자동 / 위치판 / 좌표`를 명시적으로 선택
- 생성 패널 순서 `프롬프트 → 네거티브 → 캐릭터 → 조각 → 레퍼런스 → 생성 설정`
- 출력·저장 설정은 생성 설정 안의 접힌 보조 영역
- 비용을 생성 단추보다 먼저 표시
- 이미지 임포트는 현재 작업 복원으로 연결
- img2img·인페인트, 디렉터, 모자이크는 결과 활용 도구 하나씩 열기
- 세팅의 비교 실험은 별도 제품이 아니라 현재 생성 계획의 변경 규칙으로 유지

## 완료 조건

- 기존 설정과 사용자 자료를 자동 변환하거나 삭제하지 않는다.
- 세 위치 방식이 저장·재열기·payload에서 같은 의미를 유지한다.
- 임포트·생성·세팅·비교·결과가 같은 생성 설계도와 작업 계보로 이어진다.
- 작업실 화면과 기존 호환 화면에서 기능 손실이 없다.
- 관련 회귀와 실제 브라우저 조작을 통과한 뒤 최종 전체 회귀·빌드로 닫는다.

## 금지 범위

- 외부 앱 전수 조사 반복
- 사용자 자료의 자동 마이그레이션
- `legacy_app.py` 대규모 일괄 재작성
- 저장소 밖의 `성향 표`와 `로그 편집기`
- GitHub push·Release·태그 생성
- 데스크톱 완료 전 모바일 구현

## 완료 결과

- `AI 자동 / 위치판 / 좌표`가 설정·캐스트·설계도·payload에서 같은 의미를 유지한다.
- 프롬프트 편집 도구를 분리해 가중치 표시와 도구 글자가 겹치지 않는다.
- 작업실 생성 순서, 비용 우선 표시, 결과 도구 단일 열기, 클래식 호환을 실제
  1600×1000·390×844 브라우저에서 확인했다.
- 세팅·씬·비교 결과는 파일 내용 해시와 Job 계보를 확인해 유료 중복 호출 없이
  재개하며, 계보 저장 실패를 완료로 오인하지 않는다.
- `python 검증.py`: 계약 10개, 모듈 경계 3개, 무과금 회귀 168개 통과.
- 최신 EXE 직접 기동: `/`와 `/ui/studio.css` HTTP 200.
- 포터블 ZIP·기본 자료팩·설치본과 `dist/SHA256SUMS.txt` 생성 완료.

다음 기능 작업은 사용자 승인 전 시작하지 않는다. GitHub push는
`CLAUDE_PUSH_HANDOFF.md`에 적힌 검증만 수행한 뒤 Claude가 담당한다.
