# 현재 작업

상태: **대기 — 다음 코드 작업**

## 목적

SDStudio의 프로젝트·템플릿 장점을 별도 복제하지 않고, 현재 생성 설계도와 세팅에
“공통값을 물려받고 이 설계도에서 바꾼 값만 덮는” 가벼운 상속을 연결한다.

`프로젝트 공통 설계도 → 세팅/실험 설계도 → 현재 생성에서 바꾼 값 → 최종 payload`

## 완료 조건

- 기존 그림체·캐릭터·세팅·실험·생성 값이 자동 변환되거나 사라지지 않는다.
- 공통값, 물려받은 값, 현재 설계도에서 바꾼 값을 구분해 확인한다.
- 충돌 우선순위와 최종 resolved plan을 생성 전에 보여 준다.
- 상속 원본 변경이 기존 저장 설계도를 조용히 바꾸지 않으며, 적용 여부를 고른다.
- 저장·재열기·앱 재시작 뒤 프로젝트와 설계도 연결이 유지된다.
- 프로젝트가 없는 기존 사용 흐름은 지금과 똑같이 동작한다.
- 직접 관련 기존 설계도·세팅·payload 테스트와 소스 서버 왕복을 확인한다.

- SDStudio 화면·파일 구조 그대로 복제

- 범용 조건 DSL
