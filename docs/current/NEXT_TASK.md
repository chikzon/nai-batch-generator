# 현재 작업

상태: **대기 — 다음 코드 작업**

## 목적

NAIA2.0의 캐릭터 제작 Bench와 Reference inset을 별도 프로그램처럼 복제하지 않고,
현재 `캐릭터 빌더 → 생성 → 결과 환류` 안의 **이미지 시험·변형 작업대**로 흡수한다.

`캐릭터 전체 Prompt → 시험 생성/기존 이미지 → 의상·예술적 변형 → 근거 이미지와 variation 저장 → 생성 슬롯·세팅에서 재사용`

## 완료 조건

- 캐릭터 빌더에서 선택한 캐릭터 전체 Prompt를 현재 생성 설정과 분리된 임시 시험값으로 실행한다.
- 기존 이미지나 방금 만든 결과를 Character Reference 또는 Reference inset 방식으로
  변형할 수 있고, 어느 방식을 쓰는지 생성 전에 보여 준다.
- 결과를 캐릭터의 대표 이미지·근거 이미지·variation으로 저장하되 외형·착의·
  네거티브·Reference·Vibe 원문과 기존 캐릭터 파일을 잃지 않는다.
- 저장한 variation을 생성 슬롯과 세팅 캐스트에서 명시적으로 선택할 수 있다.
- 취소·실패·앱 재시작 뒤 임시 시험 설정이 일반 생성 설정에 섞이지 않는다.
- 비용·최종 Prompt·해상도·Reference 사용을 실행 전에 확인한다.
- 직접 관련된 기존 캐릭터·img2img/Inpaint·Reference·승격 테스트와 소스 서버
  왕복으로 검증한다.

## 금지 범위

- NAIA2.0 화면·파일 구조 그대로 복제
- 캐릭터 랜덤 생성기를 기본 동작으로 강제
- 기존 캐릭터 파일·설정 자동 변환
- 6칸 Organizer
- 범용 조건 DSL·완전한 X/Y 그리드
- UI 전면 개편 또는 `legacy_app.py` 대규모 재작성
- 스마트폰 앱화
- GitHub push·Release·태그
- 저장소 밖의 `성향 표`와 `로그 편집기`
