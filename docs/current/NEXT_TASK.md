# 현재 작업

상태: **공개 저장소 문서·파일 정리**

## 목적

현재 v1.1.0 실행 화면과 README·현재 문서를 일치시키고, 제품에 필요하지 않은 내부
감사·과거 증거를 저장소 밖에 보관한 뒤 공개 `main`에서 정리한다.

## 완료 조건

- README의 네 화면과 설명이 현재 v1.1.0 동작과 일치한다.
- 내부 감사 자료는 저장소 밖에 원본·경로·SHA-256을 보존한 뒤 Git 추적에서 빠진다.
- 공개 저장소에는 실행 소스, 필요한 기본 구조 자료, 테스트·계약, 배포 도구,
  라이선스·사용자 문서만 남는다.
- 남은 Markdown의 상대 링크와 이미지가 모두 열린다.
- 개인 자료·토큰·생성물·재생성 산출물이 추적되지 않는다.
- 일반 push 뒤 원격 HEAD가 일치하고 smoke CI가 통과한다.

## 금지 범위

- 사용자 자료 삭제·변환
- 기능 코드와 테스트 의미 변경
- 파일 수를 줄이기 위한 소스·테스트·계약 합치기
- untracked 디자인 가이드 두 파일 추가·삭제
- 기존 v1.0.0·v1.1.0 태그와 Release 수정
- Git 역사 재작성·강제 push·rebase·reset
- 전체 회귀와 새 테스트
- 저장소 밖의 성향 표와 로그 편집기 접근

세부 순서는 `CLAUDE_PUSH_HANDOFF.md`를 따른다.
