# 현재 작업

## 상태

채택한 데스크톱 통합 범위와 릴리스 후보 검증 완료.

- 복원 입력 → 증거·지식 자산
- 생성 설계도 → 세팅·선택 실험
- 직렬 실행·Job 저장 → 결과 계보
- 평가·Blind ELO → 그림체·캐릭터 승격
- 포터블·자료팩·설치본 재빌드와 설치/기동/제거

## 다음 한 작업

스마트폰 1단계의 제품 경계를 확정한다.

- PC 작업실 연동형을 먼저 만들지
- 스마트폰 독립 생성까지 첫 범위에 포함할지

사용자 판단 전에는 모바일 코드·권한·패키징을 만들지 않는다.

## 금지 범위

- 완료한 외부 앱 조사 반복
- 데스크톱 기능의 근거 없는 재작성
- 사용자 자료 자동 변환·삭제
- GitHub push·Release·태그 생성
- 저장소 밖의 `성향 표`와 `로그 편집기`
