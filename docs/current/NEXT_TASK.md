# 현재 작업

상태: **대기 — 다음 코드 작업**

## 목적

작가 조합 작업공간을 열 때 멈추거나 오래 버벅이는 문제를 실제 보유 자료 규모에서
재현하고, 기존 기능을 줄이지 않은 채 첫 화면·검색·조합 갱신을 가볍게 만든다.

`작가 조합 열기 → 필요한 첫 묶음만 표시 → 검색·필터 → 조합/가중치 편집 → 저장`

## 완료 조건

- 732건 이상 실제 자료에서 열기·검색·필터·가중치 다시 뽑기의 시간을 각각 잰다.
- 접힌 영역·화면 밖 카드·대형 이미지와 통계는 필요할 때만 계산·렌더한다.
- 직접·균형·곡선·행별 무작위·고정 작가·순서·초안 복원 기능을 유지한다.
- 같은 입력과 seed의 작가·가중치 결과가 최적화 전후에 바뀌지 않는다.
- 작업 중 취소·화면 전환·재열기에서 초안과 저장본이 오염되지 않는다.
- 관련 기존 성능·작가 조합·렌더 JavaScript 회귀와 소스 서버 스모크를 통과한다.

## 금지 범위

- 작가 조합 알고리즘 의미 변경
- 자료 자동 삭제·자동 병합
- 범용 조건 DSL·완전한 X/Y 그리드
- 6칸 Organizer
- UI 전면 개편 또는 `legacy_app.py` 대규모 재작성
- 스마트폰 앱화
- GitHub push·Release·태그
- 저장소 밖의 `성향 표`와 `로그 편집기`
