# 현재 작업

상태: **구조 후속 1차 분리 완료 — 전체 점진 분리 완료 아님**

## 이번 범위

`legacy_app.py`에서 사용자 데이터 schema와 HTTP endpoint를 바꾸지 않고 다음 책임을
실제 모듈로 옮긴다.

- 정적 UI 템플릿
- 이미지 메타데이터 복원
- T5 토큰 계산
- Anlas 비용 계산
- NAI payload 조립
- 사용자 자료 잠금·원자 저장·손상 복구
- 실행권·중지·진행률 상태

기존 이름과 `start.py` 진입점은 호환 어댑터로 유지한다.

## 완료 조건

- 새 모듈 import와 Python 구문 통과
- UI 템플릿과 메타데이터 변환 결과 유지
- payload·비용·저장 복구·실행 상태 관련 기존 회귀 통과
- 전역 저장 경계 이동에 대한 전체 회귀 1회 통과
- 격리 데이터 앱 기동과 HTTP 200
- `legacy_app.py`에 남은 책임을 완료로 숨기지 않고 구조 문서에 명시

## 검증 결과

- `legacy_app.py`: 27,861줄 → 16,325줄
- Python 구문·import·모듈 경계 3/3 통과
- 비용·payload·저장 복구·실행 상태 직접 관련 회귀 30/30 통과
- 전체 무과금 회귀 171/171 통과
- 배포 전 smoke 검증 통과
- 격리 데이터 앱 기동: HTTP 200, 응답 582,326바이트
- 새 테스트·빌드·Release·push 없음
