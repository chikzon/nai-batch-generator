# 현재 작업

## 상태

구조 분리와 안전 경계 보강 완료.

## 완료 결과

- `ConfigServer.do_GET` 15줄·`do_POST` 22줄로 축소하고 기능별 route 모듈로 분리
- 인라인 CSS·JavaScript를 `web/static` 정적 자산으로 분리
- `call_nai_api`의 사용하지 않는 호환 인자 4개 제거, 나머지 생성 옵션을 keyword-only로 제한
- 설정 읽기·백업 복원·자료팩 되돌리기 실패 시 원본과 재시도 장부 보존
- 레거시 파일·라우트·페이지 템플릿 구조 상한 계약 추가
- Python 문법·외부 JavaScript 구문 통과
- 챗봇 연결 계약 10/10, 구조 계약 5/5 통과
- 전체 무과금 회귀 171/171 통과
- localhost 기동과 HTML·CSS·JavaScript 응답 통과

## 보존 사항

- 저장 schema와 사용자 자료를 변경하지 않음
- 저장소 밖의 `성향 표`와 `로그 편집기`를 건드리지 않음
- 사용자 미추적 문서 3개와 디자인 가이드 2개를 추가·삭제·수정하지 않음
- 빌드·Release·태그·push를 실행하지 않음

최신 HEAD의 포터블·설치본을 다시 빌드하고 독립 실행을 확인한 뒤에만 Release 후보로 판정한다.
