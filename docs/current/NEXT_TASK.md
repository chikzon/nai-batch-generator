# 현재 작업

## 목적

현재 데스크톱 릴리스 후보를 그대로 원격에 올리고 CI 결과만 확인한다.

## 완료 조건

- `docs/current/CLAUDE_PUSH_HANDOFF.md`의 기준 커밋과 로컬 HEAD가 일치한다.
- 작업 트리가 깨끗하고 개인 토큰·세팅·자료가 커밋되지 않았다.
- `main`을 push한 뒤 원격 커밋과 CI 결과를 확인한다.
- 기능 코드와 빌드 산출물은 다시 수정하지 않는다.

## 금지 범위

- 새 기능 구현과 UI 변경
- 사용자 자료 변환·삭제
- Release 게시와 태그 생성
- 검증이 끝난 조사를 다시 수행
- 저장소 밖의 `성향 표`와 `로그 편집기`
