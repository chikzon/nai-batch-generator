# 현재 작업

상태: **대기 — 검증 신뢰성 복구**

## 목적

실제 프롬프트 손실과 무관한 회귀 실패를 바로잡고, 회귀 fixture가 운영
`생성.log`를 오염하지 않게 해 이후 오류·완료 판정을 믿을 수 있게 만든다.

## 완료 조건

- Base·Negative·캐릭터 프롬프트 입력에는 길이 제한이 없음을 기존 회귀로 확인한다.
- 프로젝트 이름처럼 프롬프트가 아닌 제한 입력은 프롬프트 무손실 검사에서 제외한다.
- 회귀의 고의 실패·손상 복구 fixture는 임시 로그로 기록하고 기존 `생성.log`를
  삭제하거나 비우지 않는다.
- 직접 관련된 기존 검사를 먼저 통과한 뒤 `python 검증.py` 전체가 통과한다.
- 기준 커밋과 실제 검사 수를 `01-기능증거색인.md`에 기록한다.
