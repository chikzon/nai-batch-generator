## 현재 공개 상태

- 최신 태그·Release: **`v1.1.0`** (setup · portable · datapack · SHA256SUMS 4개 첨부)
- `v1.0.0` 도 그대로 남아 있다. 두 태그·Release 는 수정하지 않는다.
- README 의 화면 4장은 `v1.1.0` 실제 UI 다.

문서가 충돌하면 **최신 사용자 지시 → 이 문서 → NEXT_TASK** 순서로 판정한다.
옛 감사표의 `미구현` 과 옛 릴리스의 `완료` 를 현재 상태로 가져오지 않는다.
